BLAKE RENZI — ATHLETICS STEWARD '27–28
=====================================

Drop these four images into this folder, keeping the exact file names:

  assets/bz-portrait.jpg   → the headshot you sent first (used in the hero, portrait crop)
  assets/bz-poster.jpg     → the finished "VOTE BLAKE RENZI (BZ)" poster
  assets/bz-pizza.jpg      → the red hoodie / pepperoni selfie (used in About)
  assets/bz-hands.jpg      → the "hands up" photo (used in the campaign trail strip)

JPG or PNG both work — if you use PNG, either rename the files to .png
or change the four src="..." paths near the top of index.html.

If a file is missing, the site shows a yellow "BZ" placeholder instead of
breaking, so you can add the photos one at a time.

HOW TO EDIT
-----------
- Open index.html in any text editor. All copy is plain text.
- The three planks under "THE PLAN" are drafts — replace the headlines and
  one-line descriptions with Blake's real promises.
- The poster is displayed as an image, not a download. To swap it later,
  replace assets/bz-poster.jpg and keep the same file name.

OPENING THE SITE
----------------
Double-click index.html. The full 3D scene needs internet (Three.js loads
from a CDN + Google Fonts); without it the page still works, minus the WebGL.
